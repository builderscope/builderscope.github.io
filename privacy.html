Privacy Policy

Builder Scope Publisher — effective August 18, 2026

In short: this tool is used by one person to publish their own videos to their own accounts. It collects no personal data from anyone else, tracks nobody, and shares nothing with third parties. The only thing it stores is the access token for the operator's own accounts, kept on the operator's own computer.

1. This website

This website is a set of static pages. It uses no cookies, no analytics, no advertising, and no tracking of any kind. Nothing is collected from you by visiting it. It is hosted on GitHub Pages, which may keep standard server request logs of its own; those logs are handled under GitHub's privacy statement and are not accessible to us.

2. What the tool stores

The Tool stores only what it needs in order to publish to the operator's own accounts:

  • OAuth access and refresh tokens for social media accounts owned by the operator, obtained through each platform's official authorization flow.
  • Basic account identifiers returned by the platform during that flow, such as the account's own user ID, used to direct an upload to the correct account.
  • Publishing records — the identifier and status of a video that was uploaded, so the operator can confirm whether a post succeeded.

All of the above relates to the operator's own accounts. None of it describes anyone else.

3. What the tool does not do

  • It does not collect personal data belonging to any third party.
  • It does not read, gather, or store information about viewers, followers, or other users.
  • It does not sell, rent, share, or transfer any data to third parties.
  • It does not use data for advertising, profiling, or training machine learning models.
  • It has no public sign-up, so no one else's account can be connected to it.

4. Where data is kept

Tokens and publishing records are stored locally on the operator's own computer, in files that are not published to any code repository or shared service. They are not uploaded to any server we operate, because we do not operate one.

5. How data is used

Stored tokens are used for exactly one purpose: authenticating an upload of the operator's own video to the operator's own account on the platform that issued the token. They are not used for anything else.

6. Retention and deletion

Tokens are kept only while the tool is actively used for that account. They can be removed at any time:

  • Revoke from the platform. Removing the app's authorization in the platform's own account settings invalidates the token immediately and stops any further publishing.
  • Local deletion. Deleting the stored credential file on the operator's computer removes the token permanently.
  • On request. A deletion request sent to the address below will be carried out, and confirmed by reply, within 30 days.

Content that has already been published can be deleted at any time from the account it was posted to, using that platform's own interface.

7. Children

The Tool is not directed at children and is not available to the public, so it does not knowingly collect information from children.

8. Changes to this policy

This policy may be updated from time to time. The effective date at the top of this page will be revised when that happens, and the current version will always be published at this address.

9. Contact

Questions about this policy, or requests to delete stored data, can be sent to repaid.good2@gmail.com.
