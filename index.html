Builder Scope Publisher

A private publishing tool for uploading short-form videos to our own social media accounts.

What this tool does

Builder Scope Publisher is an internal tool operated by a single individual. It takes short-form videos that we produce ourselves and uploads them to social media accounts that we own and control, so that publishing does not have to be done by hand on each platform.

The workflow is straightforward:

  • A video is edited and rendered on the operator's own computer.
  • The operator signs in to a platform account that they own, using that platform's official OAuth flow.
  • The tool uploads the finished video file to that same account.

Who can use it

This is not a public service. There is no sign-up, no user accounts, and no way for anyone else to connect their social media account to it. It authorizes only the accounts belonging to its operator, and it is used only to publish that operator's own content.

Platforms

The tool integrates with the official publishing APIs of the platforms we post to, including TikTok, Instagram, and YouTube. It requests only the permissions needed to upload a video to the connected account — nothing else.

Data

The tool does not collect personal data from anyone. It does not gather data about viewers, it does not track visitors to this website, and it uses no cookies or analytics. The only credentials it stores are the access tokens for the operator's own accounts, kept locally on the operator's computer. Details are in the Privacy Policy.

Removing content and revoking access

Any video published by this tool can be deleted directly from the account it was posted to, using the platform's own interface, at any time. Access can be withdrawn at any time by revoking the tool's authorization in the platform's account settings, which immediately stops it from publishing anything further. Stored tokens are deleted on request — see the Privacy Policy for how.
